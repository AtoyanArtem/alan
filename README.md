# SPA Oasis — Сайт спа-салона

## 🚀 Демо
[Посмотреть на GitHub Pages](https://ваш-логин.github.io/имя-репозитория/)

## 📁 Структура проекта
- `index.html` — главная страница
- `style.css` — основные стили
- `script.js` — JavaScript для интерактивности
- `images/` — папка для изображений
- `pages/` — дополнительные страницы (услуги, контакты)

## 🛠 Технологии
- HTML5, CSS3 (Flexbox, Grid)
- Ванильный JavaScript
- Адаптивный дизайн (мобильная версия)
- Font Awesome иконы
- Google шрифты (Montserrat, Playfair Display)

## 📱 Особенности
- Чистый, спокойный дизайн в спа-тематике
- Фиксированная навигация с бургер-меню для мобильных
- Адаптивная сетка услуг
- Форма онлайн-записи
- Плавная прокрутка

## 🚀 Как запустить локально
1. Клонируйте репозиторий
2. Откройте `index.html` в браузере

Или используйте Live Server в VS Code.
